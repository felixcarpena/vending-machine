# Vending machine

A model of a vending machine: it takes coins, sells products, gives change and lets a service person restock it.

The problem statement is in [docs/challenge.md](docs/challenge.md). The work starts from the problem rather than the code. [docs/event-storming.md](docs/event-storming.md) describes what happens at the machine and lists the open questions the statement leaves. [docs/requirements.md](docs/requirements.md) settles them and describes what the machine does, and [docs/design.md](docs/design.md) describes how it is built. Instructions for running the project will be added here once there is something to run.
